=========================================================
NOTAS
=========================================================
- crear/actualizar/eliminar de CUsuario devuelven string (no void)
  porque internamente hacen "return this.obtenerTodos()", que es
  el HTML re-renderizado que se manda como respuesta HTTP.
- actualizar/eliminar de MUsuario devuelven void: no tienen return.
- CUsuario.obtenerPorId simplemente reenvía la llamada a
  MUsuario.obtenerPorId (no repite lógica de acceso a datos).
- Conexion es singleton: todos los modelos comparten la misma
  instancia de Pool (this.conexion = Conexion.getConexion()).
